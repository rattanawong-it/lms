## ข้อตกลงการออกแบบที่ใช้ร่วมกันทุกไฟล์

- โทเคนสีประกาศใน `<helmet>` ของแต่ละไฟล์: `--bg --card --muted --line --border --fg…--fg4 --pri --ok --warn --err --pur --teal` พร้อมชุด `[data-theme="dark"]` ครบ
- ฟอนต์ Inter + Anuphan (ไทย) + JetBrains Mono (ตัวเลข/รหัส) · `letter-spacing:-.018em` กับหัวข้อหน้า 26px
- ทุกไฟล์มีสวิตช์ดาร์กโหมดที่แถบบน และ prop `accent` (tweak สี)
- ไฟล์ย่อย (ไม่ใช่ Admin) มีแถบสลับหน้าจอด้านบนสุดสำหรับรีวิวงาน
- แพตเทิร์นที่ใช้ซ้ำ: การ์ดสถิติ, ตาราง grid + header สีพื้น `--bg`, ชิปสถานะจาก `this.TONE`, แถบความคืบหน้า 5-6px, สวิตช์ 40×22, ลิสต์+แผงรายละเอียดสองคอลัมน์
- โครงโค้ด: state ในคลาส · เมธอดสร้างแถวคืน `React.createElement` · `renderVals()` map เข้า `{{ }}` · หน้าใหม่ = เพิ่ม `<sc-if value="{{ isXxx }}">` + flag ใน renderVals
- ในไฟล์ Admin: ถ้าเพิ่มหน้าใหม่ ต้องเพิ่ม id ลงในอาเรย์ที่ยกเว้นของ `isGeneric` ด้วย
- มือถือ: เป้าหมายการกดทุกจุด ≥44px
